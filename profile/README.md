## Cytoscape Highlights

- **Molecules As Nodes You Measured:** Cytoscape biological network places genes, proteins, or metabolites from a table you generated, not from a social-media scrape.
- **Pathways You Can Style:** Cytoscape pathway view colors edges and nodes by an attribute you already computed, so a fold-change is visible on the map.
- **Tables Ride On The Graph:** Cytoscape node attributes keep expression, p-values, or clusters from the experiment you ran attached to each node.
- **Apps For Analyses You Repeat:** Layouts and enrichment sit as add-ons on a Cytoscape omics graph you keep, instead of a one-off screenshot.
- **Biology First, Not SNA Matrices:** This is a systems-biology canvas. Cohesion roles in a survey dataset belong in a social-network package.

## What Is Cytoscape

Cytoscape is a Windows (and multi-platform) environment for molecular and other biological networks. A lab that already produced an interaction table or an expression matrix opens Cytoscape biological network so those rows become a picture. Cytoscape pathway view is the styled canvas. Cytoscape node attributes is the spreadsheet that stays glued to nodes. Cytoscape omics graph is the session you save after a sequencing or proteomics run you performed.

People confuse it with Pajek or UCINET because all of them draw graphs. The culture here is pathways, STRING-style interactions you are allowed to use, and experimental columns. A protein you quantified in your assay is the typical node. A classroom sociogram is the wrong first example.

Work on networks from experiments you ran, public datasets you have the right to analyze, or a collaboration that delivered the table. Keep sessions with the lab notebook. Do not load another group's unpublished interactions without permission.

## Starting with Cytoscape

Prerequisites: A PC you administer and an interaction or expression table from work you are allowed to analyze.

1. **Prepare:** Export the table from the experiment you ran, with stable IDs for each molecule.
2. **Configure:** Import that table into Cytoscape biological network and map columns onto Cytoscape node attributes.
3. **Test:** Apply a layout and confirm a known hub from your assay is present.
4. **Refine:** Style Cytoscape pathway view by a statistic you computed, not by a random palette.
5. **Apply:** Save the Cytoscape omics graph with the notebook date of that run.
6. **Maintain:** Version the session when the table is reprocessed, and leave other labs' private networks out.

## Best Uses

- **Proteomics You Measured:** Cytoscape biological network from a table the mass spec already produced.
- **RNA-seq Modules You Clustered:** Cytoscape node attributes for those clusters.
- **Pathway Figure For A Paper You Write:** Cytoscape pathway view you can still edit.
- **Public Dataset You Are Allowed To Reanalyze:** Cite the source in the session.
- **Not A Survey Sociogram:** Use a social-network tool for that.
- **One Experiment Per Session:** Do not dump unrelated screens into one Cytoscape omics graph.
